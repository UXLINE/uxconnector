# UXConnector 2.18.37

## EasyVista Service Manager

- Cinq modèles entrants pour incidents, demandes de service, lieux, ordinateurs et entrées de catalogue.
- Un modèle de création sortante désactivé jusqu’à validation du rapprochement entre le lien `HREF` et le numéro RFC.
- Les modèles de la 2.18.36 sont conservés. La variante API InPark est exclue.

Les paramètres de connexion, la recette et l’écart entre les structures de réponse documentées figurent dans le [guide EasyVista](../EasyVista_Service_Manager.md).

## Contenu du ZIP de recette

Le ZIP contient le code installable, les outils d’administration, les guides d’utilisation, les notes de version et les métadonnées de publication. Les jeux de test, traces de validation et spécifications Jira/JSM sont disponibles dans les archives candidates qui les contenaient.

Les contrôles de cette archive portent sur l’intégrité du ZIP, le XML, les versions et la conservation des fichiers d’exécution et des modèles. Les tests PHP et la recette en environnement GLPI restent à effectuer.
